# The 2026 State of Agent Evaluation

*AIQ Report — published 12 March 2026. Survey of 1,204 engineering teams
running LLM agents in production, fielded January–February 2026.*

## Headline findings

- **62% of teams run no automated evaluation of their agents at all.** They
  rely on manual spot checks before release.
- 24% run automated evaluation on outcomes only. Just 9% score the trajectory
  as well as the final answer.
- Of teams that use an LLM-as-judge, **only 11% have calibrated it against
  human labels**. The rest report judge scores as if they were ground truth.
- Median golden set size is 22 tasks. The report notes this is too small to
  separate a good agent from a mediocre one at any useful confidence level.

## Methodology

Self-selected respondents recruited through three practitioner newsletters.
The report acknowledges likely over-representation of teams already interested
in evaluation, which would bias the 62% figure downward — real adoption is
probably worse.
